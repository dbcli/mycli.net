# mycli.net

A website for the mycli project.

# Running the server

### Install the dependencies

```bash
uv sync
```

### Starting the server

```bash
uv run ./develop_server.sh start
```

### Accessing

Open your favorite browser and go to http://localhost:8000 .

### Stopping the server

```bash
uv run ./develop_server.sh stop
```
